## Verified acceptance cases

Specification basis. Match an explicit token against the full relative paths of observed files.

| Case | Check | Behavior |
| --- | --- | --- |
| ` FILENAME-TOKEN-REFUSAL ` | source refusal | An empty token is refused. |
| ` FILENAME-TOKEN-QUICKSTART ` | consumer example | An installed caller matches a token found in a parent directory of a file. |

Runtime requirement. ` >=22 `
